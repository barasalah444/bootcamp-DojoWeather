# bootcamp-DojoWeather
 DojoWeather assignments

A responsive and interactive weather forecast website built using clean HTML5, CSS3, and JavaScript as part of the Full-Stack Developer bootcamp training.

##  Features

* **Interactive City Alerts:** Displays a browser notification when clicking on any city name in the navigation bar.
* **Temperature Converter:** Dynamically converts the displayed temperatures between Celsius (°C) and Fahrenheit (°F) via a dropdown menu.
* **Dismissible Cookie Banner:** A custom cookie consent policy message that can be completely dismissed upon clicking "I Accept".
* **Clean Layout:** Fully styled with custom CSS layout configurations for modern web presentation.

---

##  Technologies Used

* **HTML5:** Structured semantic elements.
* **CSS3:** Custom layout design and responsive presentation.
* **JavaScript (ES6):** Dynamic DOM manipulation for alerts, event handling, and temperature conversion logic.
